I’ve built a quiz app using React JS. The app has 12 questions based on the IT sector, and once you finish answering them, it shows your final score.
To manage the flow of the quiz, I’ve used React hooks — mainly useState for handling things like the current question and correct answer, and useContext to easily share data between components.
While making this project, I got good hands-on practice with React basics and managing state in a clean way.
